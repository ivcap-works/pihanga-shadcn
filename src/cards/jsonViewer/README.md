Renders any JavaScript value — object, array, string, number, boolean, or null —
as an interactive, collapsible tree.

Powered by `react-json-view-lite` (React 19 compatible). Click any node label
to expand or collapse it. The `collapsed` prop controls the initial depth:
`false` expands everything, `true` collapses everything, and a number N
expands nodes up to depth N (root is depth 0).
