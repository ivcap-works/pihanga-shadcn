An interactive list of clickable items with support for titles, subtitles,
start/end decorators (icons, avatars, chips, or nested cards), and collapsible
nested sub-lists.

Use it for navigation menus, search results, settings panels, or any ordered
collection that users can click to select or navigate.

Set `size` to control visual density, and `marker` to add list markers
(`"disc"`, `"decimal"`, etc.).  Each item can carry start/end decorators and
optional nested children.
