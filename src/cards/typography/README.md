A versatile text rendering card that maps semantic **levels** to the appropriate
HTML element and shadcn/ui Tailwind prose styles.

Use it to display headings, body paragraphs, blockquotes, inline code, and
muted captions without writing custom CSS.  The `level` prop controls both the
rendered HTML tag and the default visual style.

Available levels: `h1`–`h4` for headings, `p` for body text, `lead` for a
large intro paragraph, `large` for prominent but non-heading text, `small` for
fine print, `muted` for secondary captions, `blockquote`, and `code`.
