A drag-to-resize panel group backed by `react-resizable-panels`.

Arrange two or more panels side-by-side (horizontal) or top-to-bottom
(vertical), separated by drag handles.  Each panel renders a `PiCardRef`
and can specify a `defaultSize` (percentage), `minSize`, `maxSize`, and
whether it is `collapsible`.

Use it for IDE-style layouts, split-view editors, master/detail panes, or
any UI where the user should control the relative size of adjacent regions.
